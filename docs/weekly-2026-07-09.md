## Radio / DJ (you’ll feel this in channel)

1. **Your adds jump the auto-DJ queue**  
   `!add` / web add / playlists go **ahead of** whatever radio restock filled in.
   You no longer wait behind 18 auto-queued tracks. `!playnext` is still “right after current.”

2. **Auto-DJ actually mixes the internet again**  
   Seed restock is no longer library-only. Default mix is roughly **⅓ local / ⅔ YouTube**
   (short tracks only — multi-hour “study mix” junk still filtered).  
   Settings → profile: **Seed: local / YouTube / stream** + **External %** (default 66).  
   Spotify/Tidal catalogs still work best via **playlist refs** + bridge.

3. **Bumpers stop reading agent instructions**  
   No more on-air “do not invent anything; only rephrase…” or tone-guide leaks.
   Doctrine bumpers also skip ops cheatsheets / rank-gating docs. Real prose or skip.

4. **Alone-stop**  
   When the last human leaves, music **stops** (default immediate). Someone joins →
   she restocks and plays again. (`emptyChannelStopSeconds`: 0 / N / −1)

5. **Reliability for voice + reconnect**  
   - TTS **barge-in** (talk over her; music doesn’t get killed unless it was ducked for that line)  
   - Event-driven **reconnect with backoff** if TS drops  
   - Voice **transport self-heal** if send keeps failing
